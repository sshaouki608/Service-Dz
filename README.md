# DZ SERVICES 🇩🇿 - منصة الخدمات الجزائرية

منصة رقمية جزائرية متكاملة واحترافية لعرض وطلب مختلف الخدمات والإعلانات في كافة الولايات الـ 58، تجمع بين مقدمي الخدمات والحرفيين والأشخاص الذين يبحثون عنها، مع تواصل مباشر وسريع عبر واتساب والهاتف.

---

## 🌟 مميزات المنصة

1. **تصميم تجاري فاخر وعصري (UI/UX)**:
   - مستوحى من كبرى المنصات العالمية مع مراعاة الهوية الجزائرية.
   - ألوان الهوية البصرية: الكحلي الداكن (`#101B32`)، الذهبي التجاري (`#F59E0B`)، والأبيض (`#FFFFFF`).
   - دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (`RTL`).
   - دعم التبديل بين **الوضع الليلي (Dark Mode)** و**الوضع النهاري (Light Mode)**.
   - متجاوب 100% مع الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.

2. **نظام خدمات متكامل (CRUD)**:
   - إضافة خدمات جديدة مع رفع الصور ومعاينتها فورياً.
   - مراجعة إدارية مسبقة للخدمات قبل نشرها للعامة.
   - بطاقات خدمات غنية بالتفاصيل: السعر بالدينار الجزائري (DZD)، اسم الحرفي، التصنيف، الولاية، والتاريخ.
   - نظام المفضلة المحلي لحفظ الخدمات للرجوع إليها لاحقاً.
   - حالة فارغة (Empty State) أنيقة ومشجعة عند بدء التشغيل بدون خدمات وهمية، التزاماً بشروط المشروع.

3. **بحث وتصفية حية (Real-time Filtering)**:
   - بحث فوري بالعنوان والوصف واسم الحرفي والولاية.
   - تصفية حسب كافة ولايات الجزائر الـ 58.
   - تصفية حسب 12 تصنيفاً رئيسياً.
   - فرز حسب الأحدث، الأقدم، والسعر (تصاعدياً وتنازلياً)، والخدمات المميزة.

4. **تواصل ذكي عبر واتساب**:
   - تنظيف وتوحيد أرقام الهواتف الجزائرية (`05xx`, `06xx`, `07xx`, `02xx`).
   - فتح محادثة واتساب مباشرة مع رسالة مسبقة التجهيز تتضمن عنوان الخدمة واسم مقدمها لتسهيل الاتفاق.
   - أزرار اتصال هاتفي مباشر ونسخ لرقم الهاتف بنقرة واحدة.

5. **لوحة تحكم إدارية خاصة ومخفية**:
   - دخول سري عبر رمز PIN محلي (الرمز الافتراضي: `dz2025`، مع إمكانية تغييره).
   - إحصائيات دقيقة: الخدمات المنشورة، قيد المراجعة، المرفوضة، والتصنيفات.
   - قبول ونشر الخدمات بنقرة واحدة، أو رفضها، أو تعديلها، أو حذفها.
   - ميزة تمييز الخدمات (Featured ⭐).
   - إمكانية نشر خدمة مباشرة من لوحة الإدارة.
   - إدارة التصنيفات (إضافة وحذف).
   - تصدير واستيراد النسخ الاحتياطية بصيغة JSON مع فحص أمان البيانات ومنع تكرار المعرفات.

6. **تخزين بدون خادم (Zero Backend / Zero Database)**:
   - الاعتماد الكامل على `LocalStorage` للبيانات والتصنيفات والمفضلة.
   - الاعتماد على `IndexedDB` وتقنيات ضغط الصور عبر `Canvas API` لضمان سرعة التحميل وعدم تجاوز سعة التخزين.

## 🚀 كيفية التشغيل

1. **التشغيل المباشر**:
   - لا يتطلب المشروع أي بيئة تشغيل (Node.js أو خادم) ليعمل في بيئة الإنتاج.
   - يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Firefox, Safari, Edge).
   - متوافق 100% مع **GitHub Pages** بنشر الملفات مباشرة على فرع `gh-pages` أو `main`.

2. **التشغيل في بيئة التطوير**:
   ```bash
   npm run dev
   ```
   يفتح المشروع على المنفذ `http://localhost:3000`.
